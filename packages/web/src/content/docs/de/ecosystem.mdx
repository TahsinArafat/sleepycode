Eine Sammlung von Community-Projekten, die auf SleepyCode basieren.

:::note
Möchten Sie Ihr SleepyCode-bezogenes Projekt zu dieser Liste hinzufügen? Senden Sie einen PR.
:::

Sie können sich auch [awesome-sleepycode](https://github.com/awesome-sleepycode/awesome-sleepycode) und [sleepycode.cafe](https://sleepycode.cafe) ansehen, eine Community, die das Ökosystem und die Community zusammenfasst.
