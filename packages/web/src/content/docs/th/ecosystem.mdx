ชุดโครงการชุมชนที่สร้างขึ้นบน SleepyCode

:::note
ต้องการเพิ่มโครงการที่เกี่ยวข้องกับ SleepyCode ของคุณลงในรายการนี้หรือไม่ ส่งพีอาร์.
:::

คุณยังสามารถลองดู [awesome-sleepycode](https://github.com/awesome-sleepycode/awesome-sleepycode) และ [sleepycode.cafe](https://sleepycode.cafe) ซึ่งเป็นชุมชนที่รวบรวมระบบนิเวศและชุมชนไว้ด้วยกัน
