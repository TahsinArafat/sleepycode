Use `@sleepy-ai/sdk/workerd` inside a Cloudflare Durable Object. This profile uses the object's SQLite storage,
persists durable events for eviction recovery, and replaces unavailable local filesystem and process services.

```sh
bun add @sleepy-ai/sdk
```

Hold one host for the lifetime of the Durable Object instance instead of creating one for every request.

```ts
import { SleepyCodeWorkerd } from "@sleepy-ai/sdk/workerd"
import myPlugin from "./my-plugin"

export class SleepyCodeDO {
  private readonly sleepycode: Promise<SleepyCodeWorkerd.Interface>

  constructor(state: DurableObjectState) {
    this.sleepycode = state.blockConcurrencyWhile(() =>
      SleepyCodeWorkerd.create({
        storage: state.storage,
        config: { default_agent: "build" },
        plugins: [myPlugin],
      }),
    )
  }

  async fetch() {
    const sleepycode = await this.sleepycode
    return Response.json(await sleepycode.server.info())
  }
}
```

`blockConcurrencyWhile` keeps every Durable Object event out until the host is ready and resets the object if
initialization fails. The retained Promise gives request handlers direct access to the same host after startup.

```ts
constructor(state: DurableObjectState) {
  this.sleepycode = state.blockConcurrencyWhile(() =>
    SleepyCodeWorkerd.create({ storage: state.storage }),
  )
}
```

Wrangler selects SleepyCode's Workerd-safe implementations through the `workerd` package condition. Cloudflare may evict
a Durable Object without running cleanup, so correctness does not depend on `close()` being called.

```jsonc title="wrangler.jsonc"
{
  "compatibility_flags": ["nodejs_compat"]
}
```

## Customize

Customize your SleepyCode instance by registering plugins bundled with your
Worker. Pass plugins to `SleepyCodeWorkerd.create()` to customize agents, models,
tools, and other behavior:

```ts
import { Plugin } from "@sleepy-ai/plugin"
import { SleepyCodeWorkerd } from "@sleepy-ai/sdk/workerd"

const plugin = Plugin.define({
  id: "customize-agent",
  async setup(ctx) {
    await ctx.agent.transform((agents) => {
      agents.update("build", (agent) => {
        agent.description = "Builds features and fixes bugs for our team"
      })
    })
  },
})

await SleepyCodeWorkerd.create({
  storage: state.storage,
  config: { default_agent: "build" },
  plugins: [plugin],
})
```

See the [full plugins documentation](/build/plugins) for plugin hooks,
transforms, tools, and the complete plugin context.
