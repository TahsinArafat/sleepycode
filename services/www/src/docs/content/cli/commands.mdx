---
title: "Commands"
description: "Reference for the sleepycode command line."
---

Every command accepts `--help` for its full flag list, for example `sleepycode run --help`. Some server-backed commands accept `--standalone` to run a private server or `--server <url>` to target a specific one; check the command's help for its supported flags.

## run

Sends a message and prints the reply without opening the interactive interface.

```bash
$ sleepycode run "Explain this repository"
```

### CI

In CI, pass a provider API key as a secret and use standalone mode so the private server receives it. For example, this GitHub Actions job reviews the checked-out repository:

```yaml
name: SleepyCode review
on: [pull_request]

jobs:
  review:
    runs-on: ubuntu-latest
    steps:
      - uses: actions/checkout@v4
      - run: npm install --global @sleepy-ai/cli
      - run: sleepycode run --standalone --model anthropic/claude-sonnet-4-5 "Review this repository for correctness and summarize any issues."
        env:
          ANTHROPIC_API_KEY: ${{ secrets.ANTHROPIC_API_KEY }}
```

Choose a model.

```bash
$ sleepycode run --model anthropic/claude-sonnet-4-5 "Refactor parseToken"
```

Continue the last session.

```bash
$ sleepycode run --continue "Now handle the expired case"
```

Emit newline-delimited JSON for scripts.

```bash
$ sleepycode run --format json "List the TODO comments"
```

Attach files to the message.

```bash
$ sleepycode run --file src/server.ts --file src/client.ts "Review these for bugs"
```

Run with a specific agent.

```bash
$ sleepycode run --agent build "Fix the failing test"
```

View all subcommands and flags.

```bash
$ sleepycode run --help
```


```bash

```

```bash
$ sleepycode mini --model anthropic/claude-sonnet-4-5 --prompt "Summarize this repository"
```

```bash
$ sleepycode mini --help
```

## session

Manages sessions.

```bash
$ sleepycode session list
```

Limit the list and print JSON.

```bash
$ sleepycode session list --max-count 20 --format json
```

Delete a session and its child sessions.

```bash
$ sleepycode session delete ses_9c1b08
```

Export session data as JSON.

```bash
$ sleepycode session export ses_4f2a1c
```

Redact sensitive transcript and file data when exporting.

```bash
$ sleepycode session export ses_4f2a1c --sanitize
```

Import session data from a JSON file or URL.

```bash
$ sleepycode session import session.json
```

Import into a specific directory.

```bash
$ sleepycode session import session.json --directory ~/code/project
```

View all subcommands and flags.

```bash
$ sleepycode session --help
```

## auth

Manages AI providers and credentials.

```bash
$ sleepycode auth list
```

List them as JSON.

```bash
$ sleepycode auth list --format json
```

Log in to a provider.

```bash
$ sleepycode auth login anthropic
```

Log in with a specific authentication method.

```bash
$ sleepycode auth login anthropic --method key
```

Log out of a saved account.

```bash
$ sleepycode auth logout anthropic work
```

Switch the active account for an integration.

```bash
$ sleepycode auth switch anthropic work
```

View all subcommands and flags.

```bash
$ sleepycode auth --help
```

## mcp

Manages MCP (Model Context Protocol) servers.

```bash
$ sleepycode mcp list
```

Add a remote server.

```bash
$ sleepycode mcp add context7 --url https://mcp.context7.com/mcp
```

Add a local server to the global config.

```bash
$ sleepycode mcp add everything --global -- npx -y @modelcontextprotocol/server-everything
```

Add a local server with an environment variable.

```bash
$ sleepycode mcp add everything --env LOG_LEVEL=debug -- npx -y @modelcontextprotocol/server-everything
```

Add a remote server with a header.

```bash
$ sleepycode mcp add context7 --url https://mcp.context7.com/mcp --header CONTEXT7_API_KEY=secret
```

Authenticate with an OAuth-capable remote server.

```bash
$ sleepycode mcp auth sentry
```

Remove stored OAuth credentials for a server.

```bash
$ sleepycode mcp logout sentry
```

View all subcommands and flags.

```bash
$ sleepycode mcp --help
```





View all subcommands and flags.

```bash
$ sleepycode plugin --help
```

## serve

Starts the API and web server. See [Web](/cli/web).

```bash
$ sleepycode serve
```

Bind to all interfaces on a fixed port.

```bash
$ sleepycode serve --hostname 0.0.0.0 --port 4096
```

Allow a browser client from another origin.

```bash
$ sleepycode serve --cors https://app.example.com
```

View all subcommands and flags.

```bash
$ sleepycode serve --help
```

## pair

Prints one-time links, plus a QR code of the first one, that sign a browser or
app in to the server. Links expire after 5 minutes and work once.

```bash
$ sleepycode pair
```

Use an external URL in the links.

```bash
$ sleepycode pair --url https://dev.example.com
```

Pair from anywhere through an OpenTunnel remote address. This exposes the
server to the internet, so the first time it enables remote access it explains
this and asks you to accept. See [Remote access](/cli/web#remote-access).

```bash
$ sleepycode pair --remote
```

Accept without a prompt, for example in a script without a terminal.

```bash
$ sleepycode pair --remote --yes
```

View all subcommands and flags.

```bash
$ sleepycode pair --help
```

## service

Manages the background server. See [Web](/cli/web).

```bash
$ sleepycode service start
```

Restart it.

```bash
$ sleepycode service restart
```

Show its status.

```bash
$ sleepycode service status
```

Stop it.

```bash
$ sleepycode service stop
```

Read a setting.

```bash
$ sleepycode service get hostname
```

Set a setting.

```bash
$ sleepycode service set hostname 0.0.0.0
```

Allow an extra CORS origin.

```bash
$ sleepycode service set cors https://app.example.com
```

Pass an environment variable to the server process.

```bash
$ sleepycode service set env SLEEPYCODE_LOG_LEVEL DEBUG
```

Reset a setting to its default.

```bash
$ sleepycode service unset hostname
```

View all subcommands and flags.

```bash
$ sleepycode service --help
```

## reload

Reloads configuration without restarting the server. Running sessions continue with fresh services at the next step boundary.

```bash
$ sleepycode reload
```

## api

Makes a request to the running server.

```bash
$ sleepycode api GET /api/session
```

Call an operation ID with a query parameter.

```bash
$ sleepycode api session.list --param limit=10
```

Send a JSON body.

```bash
$ sleepycode api session.create --data '{"title": "New session"}'
```

Add a request header.

```bash
$ sleepycode api GET /api/session -H "accept: application/json"
```

View all subcommands and flags.

```bash
$ sleepycode api --help
```

```bash
$ sleepycode upgrade
```

```bash

```

View all subcommands and flags.

```bash
$ sleepycode upgrade --help
```


```bash

```

```bash
$ sleepycode uninstall --help
```
