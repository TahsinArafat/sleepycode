SleepyCode is an open source AI coding agent. It’s available as a terminal-based interface, desktop app, or web app.

The npm package uses a postinstall script to select the native `sleepycode` binary for your platform. The Bun and pnpm commands
explicitly allow the required script; Vite+ requires no additional flag. The mise command requires mise 2026.10.9 or later;
older versions install SleepyCode 1.

Windows package managers are not supported.


Download a standalone CLI binary for your platform.

- **macOS:** [Apple silicon](https://opencode.ai/update/api/latest/cli/sleepycode/sleepycode-darwin-arm64.zip) · [Intel](https://opencode.ai/update/api/latest/cli/sleepycode/sleepycode-darwin-x64.zip) · [Intel (baseline)](https://opencode.ai/update/api/latest/cli/sleepycode/sleepycode-darwin-x64-baseline.zip)

## Web

Access the SleepyCode web interface with the `sleepycode pair` command.

```bash
$ sleepycode pair

  URLs      http://127.0.0.1:49374
  Username  sleepycode
  Password  ********
```

Docker images use versioned tags, for example `ghcr.io/anomalyco/opencode:2.0.0`.

## Connect

SleepyCode has built in support for many LLM providers - you can connect to them
directly [in the TUI](/cli/providers) with `/connect`.

See [Providers](/providers) to configure custom providers.

If you'd like easy access to all the best coding models you can try out
[SleepyCode Console](/console).

You can also try [SleepyCode Go](/console/go) a $10/month subscription
plan that grants you access to the best open source models.

## Customize

Make SleepyCode your own by editing the [SleepyCode config](/config), [loading plugins](/plugins), [connecting MCP
servers](/mcp-servers), or [creating commands](/commands). For terminal interface themes and keybindings, see [CLI
settings](/cli/config).
