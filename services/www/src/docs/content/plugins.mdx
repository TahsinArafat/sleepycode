title: "Plugins"
---

Add published packages, versioned packages, scoped packages, or local plugin directories to `sleepycode.json(c)`.

## Configure

```jsonc title="sleepycode.jsonc"
{
  "$schema": "https://opencode.ai/config.json",
  "plugins": [
    "sleepycode-acme-plugin",
    "sleepycode-acme-plugin@1.2.0",
    "@acme/sleepycode-plugin",
    "./plugins/local",
    "../shared/plugin.ts",
    "/absolute/path/plugin.ts",
    "file:///home/me/plugins/local",
    {
      "package": "@acme/sleepycode-plugin",
      "options": {
        "agent": "reviewer",
        "strict": true,
      },
    },
  ],
}
```

Relative paths resolve from the config file containing the entry. Plugin arrays from applicable config files are applied
from lowest to highest precedence instead of replacing one another.

```text
~/.config/sleepycode/sleepycode.jsonc
./sleepycode.jsonc
./.sleepycode/sleepycode.jsonc
```

## Discover

SleepyCode also loads direct `.ts` and `.js` files and immediate plugin package directories from every discovered
`.sleepycode/plugins/` directory.

```text
.sleepycode/
└── plugins/
    ├── concise.ts
    ├── reviewer.js
    └── acme-package/
```

Global plugins use the same discovery layout under the SleepyCode config directory.

```text
~/.config/sleepycode/plugins/
```

A `plugins/` directory beside a project-root `sleepycode.json(c)` is not discovered automatically; configure its files
explicitly or move it under `.sleepycode/`.

```jsonc title="sleepycode.jsonc"
{
  "plugins": ["./plugins/local"]
}
```

## Control

Plugin entries are processed in order. Prefix an ID or wildcard with `-` to disable it, use `*` for every plugin, and
use `.*` to match an ID prefix. A later ID re-enables a plugin.

```jsonc title="sleepycode.jsonc"
{
  "plugins": ["*", "-sleepycode.provider.*", "sleepycode.provider.openai", "-acme.reviewer"]
}
```

Two built-in plugins ignore removals so that a repository cannot switch off
[policy](/policies) enforcement: `sleepycode.config.policy` and
`sleepycode.provider.sleepycode`, the Console connection that delivers organization
policy.

## Manage

Install, list, check, update, or remove global package plugins with the CLI.

```sh
sleepycode plugin add sleepycode-acme-plugin@1.2.0
sleepycode plugin list
sleepycode plugin list --builtin
sleepycode plugin check
sleepycode plugin update
sleepycode plugin update sleepycode-acme-plugin
sleepycode plugin remove sleepycode-acme-plugin@1.2.0
```

`plugin check` checks server and TUI-only package plugins for updates. `plugin update` updates every outdated package;
pass a configured package target to check or update only that package. Local plugins and exact package revisions are skipped.

Package installation accepts npm names with versions, tags, or ranges, plus npm-compatible Git package specifications.
Git repositories can use hosted shortcuts, HTTPS, or SSH, including private repositories available through your existing
Git credentials.

```sh
sleepycode plugin add @acme/sleepycode-plugin@latest
sleepycode plugin add github:acme/sleepycode-plugin
sleepycode plugin add git+ssh://git@github.com/acme/sleepycode-plugin.git#main
sleepycode plugin add 'github:acme/plugins#main::path:packages/sleepycode-plugin'
```

Branches, tags, complete commit hashes, and npm's `::path:` repository-subdirectory selectors are supported. Configure
local paths directly; tarball and npm alias targets are not accepted by `plugin add`.

## Reload

Changes under watched config directories reload automatically. Server startup loads cached package plugins immediately,
installs missing packages in the background, and checks unpinned npm and Git plugins for updates without changing the
installed package. Exact npm versions and full Git commit hashes stay pinned. Changes to unwatched local dependencies may
still require restarting SleepyCode.

```sh
touch .sleepycode/plugins/concise/index.ts
sleepycode service restart
```

## Terminal

CLI-only plugins are configured separately and remain active when connected to a remote server.

```json title="cli.json"
{
  "plugins": ["sleepycode-acme-cli"]
}
```
